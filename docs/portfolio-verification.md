기존 학습 파일 중 65,462개가 새 검증 목록으로 이동했다. 기존 학습에 없던 검증 파일 59,261개가 새 학습 목록에 들어왔다. 따라서 학습 고유 파일은 6,201개 줄었지만 전체 train+dev 파일 풀은 796,714개로 같고, 추가·삭제된 파일 경로는 없었다.

파일 중복은 경로 문자열 기준이다. 내용이 같은 다른 경로의 음성, 동일 발화의 다른 파일, 같은 문장의 다른 합성 결과는 검사하지 않았다. 그룹 ID도 실제 화자·합성 시스템·파일명이 섞여 있어, 그룹 중복 0을 화자 독립성으로 해석하지 않는다.

[병합 코드](../scripts/03_train/merge_manifests.py) · [검증 코드](../scripts/04_analyze/verify_splits.py) · [집계 결과](split_verification.json)

검증 코드는 평가 목록 T1/T2/T3에 학습 파일이 포함되면 종료 코드 1을 반환한다. train/dev 겹침과 그룹 ID 겹침은 보고서에 표시하지만 이 조건만으로 실패 종료하지는 않는다. 실제 CI에는 연결하지 않았다. 집계 JSON에는 파일별 경로를 포함하지 않는다. JSON의 `speaker_semantics.verdict`는 파일/ID 비율로 추정한 분류이며 실제 ID의 의미를 증명하지 않는다. 실제 생성 규칙은 [분할 명세](../데이터_분할_명세.md)의 데이터셋별 설명을 기준으로 한다.

## 확인 범위

- 지표 계산 단위 테스트: `python -B scripts/03_train/test_metrics.py`로 20개 통과.
- LCNN 생성자: 2·4·8초 설정의 첫 분류기 입력 차원 3,584·7,680·15,872 확인. 추론 성능 평가는 아님.
- 검증기 종료 코드: 합성 CSV에서 평가·학습 경로가 분리되면 0, 겹치면 1 반환 확인.
- 분할 집계: 기존 목록과 C_all_v2를 검증 스크립트로 비교. 실행 결과는 위 JSON 참조.
- 모델 4종 forward/backward 통과는 기존 프로젝트 기록이다. 이번 공개 준비에서 학습이나 전체 모델 검증을 재실행하지 않았다.
- 웹 데모: 코드의 동시성·버퍼 처리 범위를 검토했다. 실제 마이크 입력, 동시 사용자 부하, GPU 추론 지연을 이번 작업에서 검증하지 않았다.

## 결과 해석과 남은 작업

기존 C_all 체크포인트는 학습 파일과 겹치는 검증 목록으로 선택했다. 기존 평가값을 수정 후 최종 성능으로 제시하지 않는다. T2의 그룹 분할 문제와 실제 화자·합성 시스템의 독립성은 별도로 해결해야 한다.

평가 기준을 먼저 정하고, 학습·평가 목록을 다시 만든 뒤 대표 모델을 재학습·평가할 계획이다. 증강 모델도 같은 잡음 조건에서 비교해야 한다.

## 공개 범위

데이터 병합 수정, 분할 검증 스크립트, 분할 명세, 로컬 웹 데모를 공개한다. 기존 모델 파일의 논문 참고 표기만으로 직접 작성과 공개 코드 수정의 경위까지 판단하지 않았다. 모델별 원 구현 저장소와 차용 범위는 작성자 확인이 필요하다.
