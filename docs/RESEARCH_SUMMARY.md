# 연구 종합 보고서

## 한국어 딥페이크 음성 탐지를 위한 경량 모델의 교차 언어 전이 가능성 분석

**Cross-Lingual Transferability Analysis of Lightweight Models for Korean Audio Deepfake Detection**

---

## 1. 연구 질문과 답변

### RQ1. 경량 모델의 한국어 딥페이크 탐지, 가능한가?

> *다국어로만 학습한 경량 모델이 한국어 딥페이크를 탐지할 수 있는가? 한국어 데이터를 추가하면 임동훈(2024)이 보고한 EER 50% 실패를 극복할 수 있는가?*

**답변: 가능하다. 단, 한국어 데이터 포함이 필수 조건이다.**

| 조건 | 모델 | 한국어(T1) EER | 판정 |
|------|------|---------------|------|
| 다국어만 (C1, 한국어 미포함) | AASIST | 71.60% | 완전 실패 |
| 다국어만 (C1) | LCNN | 62.95% | 완전 실패 |
| 다국어만 (C1) | RawNet2 | 66.01% | 완전 실패 |
| 다국어+한국어 (C2) | AASIST | 1.43% | 탐지 성공 |
| 다국어+한국어 (C2) | LCNN | 0.20% | 사실상 완벽 |
| **전체 통합 (C_all)** | **AASIST** | **2.44%** | **탐지 성공** |
| **전체 통합 (C_all)** | **LCNN** | **0.20%** | **사실상 완벽** |

한국어 미포함(C1)으로 학습한 모든 모델은 EER 60~72%로 랜덤 추측보다 나쁜 성능을 보였다. 그러나 한국어를 포함한 데이터(C2, C_all)로 학습하면 EER 0.20~2.44%로 급격히 개선된다. 이는 임동훈(2024)의 50% 실패가 경량 모델의 본질적 한계가 아닌, **학습 데이터에 한국어가 없었기 때문**임을 실증한다.

### RQ2. 데이터 커버리지 vs 모델 아키텍처, 무엇이 더 중요한가?

> *모델 성능과 일반화를 결정하는 지배적 요인은 모델 아키텍처인가, 학습 데이터의 커버리지인가?*

**답변: 데이터 커버리지가 압도적으로 중요하다.**

Phase 1에서 모든 모델이 동일한 실패 패턴을 보였다.

| 학습 데이터 | 실패 테스트셋 | 실패 EER 범위 | 원인 |
|------------|-------------|-------------|------|
| C1 (다국어) | T1 (한국어 SpeechFake) | 62.9~71.6% | T1 유형 데이터 미포함 |
| C2 (다국어+한국어) | T2 (KoAAD) | 35.3~59.8% | T2 유형 데이터 미포함 |
| C3 (한국어만) | T3 (MLAAD 다국어) | 37.8~81.3% | T3 유형 데이터 미포함 |

모델 아키텍처(AASIST/LCNN/RawNet2)와 무관하게, 학습 데이터에 포함되지 않은 도메인에서는 일관되게 실패한다. 반대로 C_all(전체 통합)로 학습하면 **같은 아키텍처가 모든 테스트셋에서 성공**한다.

가장 극적인 사례:

```
LCNN + C3  → T3 EER: 81.30% (완전 실패)
LCNN + C_all → T3 EER:  0.03% (사실상 완벽)
```

동일 모델(LCNN)이 데이터만 바꿔 **EER 81.30% → 0.03%**, 2,710배 개선되었다. 이는 일반화 성능의 지배적 변인이 모델 구조가 아닌 데이터 커버리지임을 결정적으로 보여준다.

### RQ3. 어떤 경량 모델이 최적인가?

> *AASIST, LCNN, RawNet2 중 한국어 딥페이크 탐지에 최적인 경량 모델은 무엇인가?*

**답변: LCNN이 종합 최적, AASIST가 극한 경량 최적이다. RawNet2는 부적합하다.**

### RQ4. 교차 언어 전이는 작동하는가?

> *다국어 데이터만으로 한국어 딥페이크를 탐지하는 교차 언어 전이가 경량 모델에서 가능한가?*

**답변: 경량 모델에서 교차 언어 전이는 실패한다.**

C1(다국어, 한국어 미포함)으로 학습한 모든 모델의 한국어(T1) EER:

| 모델 | T1 EER | 판정 |
|------|--------|------|
| AASIST | 71.60% | 실패 |
| LCNN | 62.95% | 실패 |
| RawNet2 | 66.01% | 실패 |

임동훈(2024)의 결과(50~66% EER)를 재확인한다. 다만 SpeechFake(2025)는 W2V+AASIST(SSL 기반, 300M params)로 한국어 EER 0.03%를 보고한 바 있다. 이는 교차 언어 전이가 SSL 사전학습 모델에서는 가능하나, SSL 없는 경량 모델에서는 불가능함을 시사한다.

## 3. 연구 스토리: 실패에서 해결까지

### 3.1 출발점: 임동훈(2024)의 문제 제기

임동훈, 한종기(2024)는 MLAAD(다국어, 한국어 미포함)로 학습한 경량 모델이 한국어 테스트(KoAAD)에서 EER 50~66%로 완전 실패함을 보고했다. 이는 두 가지 해석이 가능했다.

- **해석 A**: 경량 모델은 본질적으로 한국어 딥페이크를 탐지할 수 없다 (모델 한계)
- **해석 B**: 학습 데이터에 한국어가 없었기 때문이다 (데이터 문제)

어느 해석이 맞는지를 실증적으로 규명하는 것이 본 연구의 출발점이었다.

### 3.2 Phase 1: 문제 재현과 원인 분리 (9개 실험)

3개 모델(AASIST, LCNN, RawNet2) x 3개 데이터 조합(C1: 다국어만, C2: 다국어+한국어, C3: 한국어만)으로 9개 실험을 설계하여, 모델 아키텍처와 데이터 구성의 효과를 분리 관찰했다.

**실패 재현 성공:**
C1(다국어, 한국어 미포함)으로 학습한 결과, 모든 모델이 T1(한국어) EER 63~72%를 기록하며 임동훈(2024)의 실패를 재현했다.

**핵심 발견 1 — 한국어 포함 시 극복 가능:**
C2(한국어 포함)로 학습한 AASIST는 T1 EER 1.43%를 달성했다. **해석 B(데이터 문제)가 정답**임이 확인되었다.

**핵심 발견 2 — 교차 도메인 일반화 실패 패턴:**
하지만 새로운 문제가 드러났다. 모든 모델에서, 학습 데이터에 포함되지 않은 유형의 테스트셋에서 일관된 실패가 나타났다.

```
C1 학습 → T1 실패 (한국어 SpeechFake 유형 미포함)
C2 학습 → T2 실패 (KoAAD 유형 미포함)
C3 학습 → T3 실패 (MLAAD 다국어 유형 미포함)
```

이 패턴은 3개 모델 모두에서 동일하게 나타났으며, 이는 **모델 아키텍처가 아닌 데이터 커버리지가 일반화의 결정적 요인**임을 시사했다.

**핵심 발견 3 — 대형 모델의 무의미:**
RawNet2(18.5M params)는 AASIST(229K)보다 81배 무거웠지만, 어떤 데이터 조합에서도 성능 우위를 보이지 못했다. 모델을 키우는 것은 이 문제의 해법이 아니었다.

### 3.3 Phase 1의 한계와 가설

Phase 1 결과는 강력한 시사점을 주었지만, 한 가지 미해결 질문이 남았다.

> **"모든 유형의 데이터를 통합(C_all)하면, 모든 테스트셋에서 일반화가 달성되는가?"**

이는 "데이터 커버리지가 지배적 요인"이라는 발견의 자연스러운 연장선이었다. 만약 C_all로 모든 실패가 해결된다면, 데이터 커버리지 가설이 확정적으로 입증되는 것이다.

### 3.4 Phase 2: C_all로 일반화 문제 해결

C1+C2+C3을 통합한 C_all 데이터셋(학습 1,067,960 / 검증 176,792 샘플)을 구성하고, 3개 모델 모두에 대해 실험을 수행했다.

**결과: 3개 모델 모두에서 일반화 실패가 완전히 해결되었다.**

Phase 1 최악 케이스 → Phase 2 C_all 비교:

| 비교 | Phase 1 (최악) | Phase 2 (C_all) | 개선 배율 |
|------|--------------|----------------|----------|
| LCNN → T3 | 81.30% | 0.02% | 4,065x |
| LCNN → T2 | 57.35% | 0.19% | 302x |
| RawNet2 → T3 | 65.81% | 0.21% | 313x |
| RawNet2 → T2 | 59.79% | 0.37% | 162x |
| AASIST → T1 | 71.60% | 2.44% | 29x |
| AASIST → T2 | 35.29% | 1.50% | 24x |

**데이터 커버리지 가설이 확정적으로 입증되었다.** 학습 데이터가 테스트 도메인을 포괄하면, 경량 모델로도 99%+ 정확도의 범용 탐지가 가능하다.

### 3.5 스토리 요약

```
임동훈(2024): "경량 모델은 한국어에서 실패한다" (EER 50%)
       ↓
Phase 1: 실패를 재현하되, 원인을 분리
       ↓
발견: 모델 한계가 아니라 데이터 부재가 원인
발견: 데이터 커버리지 = 일반화의 지배적 요인
발견: 대형 모델(RawNet2)은 해법이 아님
       ↓
Phase 2: 데이터 커버리지를 극대화(C_all)
       ↓
결과: EER 81.30% → 0.03% (LCNN)
결과: 모든 테스트셋에서 99%+ 정확도 달성
       ↓
결론: 경량 모델의 한국어 딥페이크 탐지는
      "가능한가?"가 아니라 "데이터를 어떻게 구성하는가?"의 문제
```

## 4. 가설 검증 결과

연구계획서에서 설정한 4개 가설의 검증 결과:

| 가설 | 내용 | 기준 | 결과 | 판정 |
|------|------|------|------|------|
| H1 | C1(다국어)만으로는 한국어 탐지 실패 | T1 EER > 30% | AASIST 71.6%, LCNN 63.0%, RawNet2 66.0% | **채택** |
| H2 | C2(다국어+한국어)에서 EER 10% 미만 | T1 EER < 10% | AASIST 1.4%, LCNN 0.2%, RawNet2 0.8% | **채택** |
| H3 | AASIST가 교차 언어 전이에서 가장 우수 | C1에서 AASIST EER 최저 | AASIST 71.6% vs LCNN 63.0% (LCNN이 낮음) | **기각** |
| H4 | C2가 C3보다 우수 | C2 EER < C3 EER | 조건부: T1에서 C2 우위, T2에서 C3 우위 | **부분 채택** |

**H3 기각에 대한 해석:** C1(교차 언어 전이) 조건에서는 모든 모델이 실패(EER 63~72%)하므로, 모델 간 교차 전이 능력 차이는 실질적으로 무의미하다. SpeechFake(2025)에서 보고한 AASIST의 교차 전이 성공(EER 3.46%)은 SSL 사전학습 또는 동일 TTS 생성기 조건에서만 유효한 것으로 보인다.

**H4 부분 채택에 대한 해석:** C2와 C3은 각각 포함하지 않는 도메인의 테스트셋에서 실패한다. "어느 조합이 더 나은가"라는 질문 자체가 부적절하며, 정답은 **"두 조합을 모두 포함하는 C_all이 필요하다"**이다.

## 5. 실용적 기여

### 5.1 확정된 학술적 기여

| # | 기여 | 근거 |
|---|------|------|
| 1 | **한국어 딥페이크 탐지의 경량 모델 가능성 최초 실증** | LCNN(1.37M) C_all: 전 테스트셋 EER 0.03~0.20%, AUC 0.9999 |
| 2 | **임동훈(2024) 실패 원인 규명** | 50% 실패는 모델 한계가 아닌 한국어 학습 데이터 부재에 기인 |
| 3 | **데이터 커버리지 > 모델 아키텍처 정량 입증** | 동일 LCNN이 데이터만으로 EER 81.30% → 0.02% (4,065배 개선) |
| 4 | **모델 규모 증가의 비효율성 실증** | RawNet2(18.5M)가 C_all에서도 LCNN(1.37M)보다 모든 지표 열위. 13.5배 무거우나 이점 없음 |
| 5 | **실용적 모델 선택 가이드 제공** | 서버: LCNN (0.74ms, 1,360 sps), 모바일: AASIST (0.87MB, 229K) |

### 5.2 실용적 활용 방안

**5.2.1 실시간 보이스피싱 탐지**

LCNN + C_all 모델은 0.74ms 추론 속도로 실시간 통화 분석이 가능하다. 4초 단위 판정 시, 단일 GPU에서 초당 1,360건 동시 처리가 가능하여 통신사급 트래픽에도 대응 가능하다.

| 지표 | LCNN + C_all | 요구 수준 |
|------|-------------|----------|
| 추론 속도 | 0.74ms | < 100ms (실시간) |
| 정확도 | 99.90%+ | > 95% |
| 모델 크기 | 5.21MB | < 50MB (모바일) |
| 처리량 | 1,360 sps | > 100 sps (서버) |

**5.2.2 모바일/임베디드 배포**

AASIST + C_all은 0.87MB, 229K 파라미터로 스마트폰 온디바이스 배포에 적합하다. 전 테스트셋 EER 3% 미만으로 실용적 수준의 탐지가 가능하다.

**5.2.3 한국어 딥페이크 탐지 시스템 구축 가이드**

본 연구 결과에 기반한 실무적 권장 사항:

1. **데이터 구성이 최우선이다.** 모델 아키텍처 선택보다 학습 데이터의 도메인 커버리지 확보에 투자하라.
2. **학습 데이터에 대상 언어/도메인을 반드시 포함하라.** 교차 언어 전이에 의존하지 말 것.
3. **모델을 키우지 말고 데이터를 키워라.** 229K 모델이 18.5M 모델보다 나을 수 있다.
4. **서버에서는 LCNN, 모바일에서는 AASIST를 사용하라.**

### 5.3 선행 연구와의 비교

| 모델 | SSL | 파라미터 | 한국어 EER | 출처 |
|------|-----|---------|-----------|------|
| LCNN-LSTM | X | ~1.5M | 50.85% | 임동훈(2024) |
| Whisper-LCNN | X | ~1.5M | 66.36% | 임동훈(2024) |
| AASIST | X | 297K | 3.46% | SpeechFake(2025) |
| W2V+AASIST | O | 300M+ | 0.03% | SpeechFake(2025) |

본 연구의 LCNN + C_all(EER 0.20%)은 SSL 없이 W2V+AASIST(EER 0.03%, 300M+ params)에 근접하는 성능을 달성했다. 파라미터 수는 219배 적고, SSL 사전학습 없이 달성한 결과이다.

## 6. 한계 및 후속 연구

### 6.1 본 연구의 한계

| 한계 | 설명 | 영향 |
|------|------|------|
| 모듈식 프레임워크 미적용 | Feature/Enhancement/Aggregation 교체 실험 미수행 | 최적 조합 탐색 불가 |
| 한국 고유 TTS 미포함 | Supertone, Typecast, CLOVA Dubbing 등 미검증 | Cross-generator 일반화 불확실 |
| 증강/강건성 미평가 | 노이즈, 짧은 발화, 코덱 압축 등 미실험 | 실전 환경 성능 불확실 |
| SSL 베이스라인 부재 | W2V+AASIST와의 동일 조건 직접 비교 미수행 | 정량적 격차 추정에 의존 |

### 6.2 후속 연구 방향

1. **모듈식 아키텍처 탐색**: 연구제안서의 4-Stage 프레임워크(Feature → Enhancement → Backbone → Aggregation) 적용
2. **SSL 비교 실험**: XLS-R Frozen → 경량 head 구성으로 성능/비용 트레이드오프 정량화
3. **강건성 평가**: 노이즈(MUSAN, SNR 0~20dB), 짧은 발화(2초/4초/8초), 코덱 압축
4. **한국어 TTS 대응**: Supertone, Typecast 등 한국 상용 TTS 생성 음성 탐지 검증
5. **지식 증류**: W2V+AASIST → LCNN/AASIST로의 지식 증류를 통한 성능 격차 추가 축소
