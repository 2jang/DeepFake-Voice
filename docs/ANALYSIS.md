# Phase 2 실험 결과 분석

## 실험 개요

- 모델 3종: AASIST (229K), LCNN (1.37M), RawNet2 (18.5M)

- 평가셋 3종: T1 (SpeechFake 한국어), T2 (KoAAD holdout), T3 (MLAAD 다국어)
- 총 9개 실험 (3 models x 3 combos)

## 실패 분석

### 1. 데이터 조합별 일반화 실패 (핵심 문제)

모든 모델에서 **학습 데이터에 포함되지 않은 유형의 테스트셋에서 일반화가 실패**하는 패턴이 일관되게 나타남:

| 학습 조합 | 실패 테스트셋 | 실패 EER 범위 | 원인 |
|-----------|-------------|-------------|------|
| C1        | T1          | 0.63~0.72   | C1 학습 분포에 T1 유형(한국어 SpeechFake) 미포함 |
| C2        | T2          | 0.35~0.60   | C2 학습 분포에 T2 유형(KoAAD holdout) 미포함 |
| C3        | T3          | 0.38~0.81   | C3 학습 분포에 T3 유형(MLAAD 다국어) 미포함 |

이는 모델 아키텍처의 문제가 아니라 **학습 데이터 커버리지 부족**이 근본 원인.

### 2. 모델별 특성

**AASIST (229K params)**
- 가장 경량이면서 일반화 밸런스가 상대적으로 양호
- c2 조합에서 T1=0.014, T3=0.005로 우수, T2만 0.353
- 학습 안정성: c1에서 epoch 4 이후 dev EER 정체 (0.11~0.13 맴돌이)

**LCNN (1.37M params)**
- 추론 속도 최고 (~1ms), 학습 데이터 내 성능은 거의 완벽 (dev EER ~0.000)
- OOD 성능 급락이 가장 심함 (c1-T2: 0.764, c3-T3: 0.813)
- 과적합 경향이 강함: dev에서 완벽하지만 OOD에서 무너짐

**RawNet2 (18.5M params)**
- 가장 무거움 (70.7MB, AASIST의 81배) 이나 성능 이점 없음
- 추론 속도도 가장 느림 (4.2ms)
- 파라미터 대비 효율이 매우 낮음

### 3. 학습 불안정 패턴

- **고정 LR (0.0001)**: 스케줄러 없이 학습하여, 초반에 best 도달 후 나머지 에포크가 낭비됨
  - 예: aasist_c1은 epoch 4가 best, 이후 10 에포크 동안 개선 없이 early stop
- **Data Augmentation 부재**: 원본 오디오만 사용, 노이즈/코덱/속도 변환 등 미적용
- **일부 실험에서 F1=0.000**: lcnn_c1의 T2, rawnet2_c1의 T2에서 모든 샘플을 한 클래스로 예측

## 개선 방안

### Phase 2.5: C_all 통합 학습 (즉시 실행 가능)

C1+C2+C3 전체 데이터를 합쳐서 학습. 모든 테스트셋 분포를 커버.

- 학습 데이터: ~1,067,963 샘플 (C1: 373K + C2: 556K + C3: 139K)
- Dev 데이터: ~176,795 샘플 (C1: 70K + C2: 96K + C3: 11K)
- AASIST 우선 실행 (가장 경량, 일반화 잠재력 높음)

### Phase 2.5+: 학습 파이프라인 개선

| 개선 항목 | 기대 효과 | 난이도 |
|-----------|----------|--------|
| CosineAnnealingLR | 학습 후반 안정화, 조기 정체 방지 | 낮음 |
| Data Augmentation (noise, speed, codec) | OOD 일반화 향상 | 중간 |
| Focal Loss | OOD에서 과신 방지, 경계 샘플 집중 | 낮음 |
| Mixup / SpecAugment | 정규화 효과, 과적합 완화 | 중간 |

### Phase 3: 앙상블 (C_all 결과 확인 후)

단일 모델로 부족할 경우, 데이터 조합별 best 모델의 스코어 평균:
- AASIST_c2 (T1/T3 강점) + AASIST_c3 (T2 강점)
- 또는 C_all 모델 + 조합별 specialist 모델
